## 🚀 Three Simple Steps

### Step 1: Deploy Google Apps Script (10 min)
- Go to script.google.com
- Create new project
- Copy GoogleAppsScript.js code
- Paste into editor
- Update SPREADSHEET_ID
- Deploy as Web App
- Get deployment URL ✓

### Step 2: Configure AlenkaAssistant (3 min)
- Edit GoogleSheetsConfig.json
- Paste deployment URL
- Paste sheet ID
- Set enabled: true
- Save ✓

### Step 3: Test (2 min)
- Build project
- Run app
- Create request
- Save to Sheets
- Verify data ✓

## 📋 The 3 Values You Need

1. **Spreadsheet ID**
   ```
   From: https://docs.google.com/spreadsheets/d/1BxiMVs0XRA5nFMXT3PJiEkVQZGzGkL8JzIgnKPZCH3c/edit
   Copy: 1BxiMVs0XRA5nFMXT3PJiEkVQZGzGkL8JzIgnKPZCH3c
   ```

2. **Deployment URL**
   ```
   From: Google Apps Script after deployment
   Copy: https://script.google.com/macros/d/1a2b3c4d.../userweb
   ```

3. **Sheet Name**
   ```
   From: Sheet tabs in Google Sheet
   Usually: Sheet1
   ```
